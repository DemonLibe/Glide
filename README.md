# MacPlayer

Нативный видеоплеер для macOS на Apple Silicon: 4K 120 fps, MKV, WebM и всё,
что умеет FFmpeg.

## Два движка

| | AVFoundation | libmpv (FFmpeg) |
|---|---|---|
| Форматы | MP4, MOV, M4V, HLS | **MKV, WebM**, AVI, TS/M2TS, FLV, WMV, OGV, MPEG, VOB… |
| Кодеки | HEVC, H.264, ProRes, AV1 (M3+) | всё вышеперечисленное + VP9, VP8, AV1 (программно на M1/M2), MPEG-2/4, VC-1 |
| Аппаратное декодирование | VideoToolbox | VideoToolbox (HEVC, H.264, VP9, AV1 на M3+, ProRes) |
| HDR | нативный EDR | тонмаппинг в SDR |
| Субтитры | встроенные в MP4/MOV | SRT, ASS/SSA, PGS, VobSub, внешние файлы рядом с видео |

Движок выбирается автоматически: для MP4/MOV используется AVFoundation (так ниже
расход энергии и есть нативный HDR), для остальных форматов — mpv. Если
AVFoundation не может декодировать файл (например, AV1 на M1 или VP9 внутри MP4),
плеер сам переключается на mpv. Какой движок работает сейчас, видно в
статистике (I).

## Почему он тянет 4K120

- **Аппаратное декодирование** через VideoToolbox в обоих движках, без
  копирования кадров: IOSurface идёт прямо в композитор или в текстуру OpenGL.
- **Кадры синхронизированы с vsync**: AVPlayerLayer и OpenGL-слой mpv
  отрисовываются по сигналу экрана, на ProMotion — с частотой 120 Гц.
- **Интерфейс не мешает видео**: SwiftUI не участвует в выводе кадров, а
  таймлайн обновляется отдельно от остального окна.
- **Отзывчивая перемотка**: запросы на перемотку схлопываются, так что
  скраббинг по 4K HEVC с длинным GOP не тормозит.

## Возможности

- Открытие через ⌘O, перетаскивание файлов или папки (плейлист), «Открыть в
  программе» из Finder.
- Окно подстраивается под пропорции видео.
- Скорость 0.25×–4× без изменения высоты звука, покадровый шаг вперёд и назад.
- Выбор аудиодорожек и субтитров.
- Повтор и автопереход к следующему файлу.
- Статистика (I): движок, разрешение, кодек, HDR, тип декодирования
  (аппаратный или программный), fps файла, **реально показанные fps**, частота
  экрана, пропущенные кадры, битрейт.

## Горячие клавиши

Работают при любой раскладке, в том числе русской.

| Клавиша | Действие |
|---|---|
| Пробел / K | Пуск / пауза |
| ← / → | −5 / +5 с (⇧ — 30 с, ⌥ — один кадр) |
| , / . | Кадр назад / вперёд |
| ↑ / ↓ | Громкость |
| M | Без звука |
| [ / ] | Скорость медленнее / быстрее, ⌫ — 1× |
| 0–9 | Переход на 0–90 % |
| F / Return, Esc | Полный экран / выход |
| I | Статистика |
| L | Повтор |
| N / P, ⌘→ / ⌘← | Следующий / предыдущий файл |
| Двойной клик | Полный экран |

## Установка готовой сборки

1. Скачайте `MacPlayer.dmg` во вкладке **Actions** (артефакт `MacPlayer-arm64`)
   или в **Releases**.
2. Перетащите MacPlayer в «Программы».
3. Приложение подписано ad-hoc, а не сертификатом Apple Developer, поэтому при
   первом запуске macOS его заблокирует. Чтобы разрешить запуск, откройте
   «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно
   открыть». Или выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/MacPlayer.app
   ```

Чтобы выпустить релиз, отправьте тег: `git tag v1.0 && git push origin v1.0`.
CI соберёт DMG и прикрепит его к релизу.

## Сборка вручную

Нужны Mac на Apple Silicon, macOS 14+ и Xcode 15+.

```bash
brew install mpv pkgconf
./build_app.sh                 # build/MacPlayer.app, полностью автономный
./Packaging/make_dmg.sh        # build/MacPlayer.dmg
```

`build_app.sh` копирует libmpv, FFmpeg и остальные зависимости из Homebrew в
`MacPlayer.app/Contents/Frameworks` (`Packaging/bundle_dylibs.py`), поэтому на
целевом Mac Homebrew не нужен.

Проверка встроенного mpv: `MacPlayer.app/Contents/MacOS/MacPlayer --selftest видео.mkv …`

## Ограничения

- Для 4K 120 fps нужен экран 120 Гц: ProMotion или внешний монитор. В режиме
  энергосбережения macOS ограничивает частоту до 60 Гц.
- На M1/M2 нет аппаратного декодера AV1, поэтому 4K AV1 декодируется на CPU и
  может не успевать при 120 fps. HEVC, H.264 и VP9 декодируются аппаратно.
- HDR в MKV/WebM выводится с тонмаппингом в SDR, а не в EDR.
- libmpv и FFmpeg из Homebrew распространяются по GPL, поэтому распространять
  сборку нужно на условиях GPL.
